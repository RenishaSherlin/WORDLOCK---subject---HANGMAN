# 🔐 WORDLOCK - Subject Challenge Hangman

WORDLOCK is an interactive Python-based Hangman game that combines
traditional word guessing with subject-based learning.

Players choose their favourite subject and answer questions related
to that subject while trying to discover the hidden word.

## 🎮 Features

- 📚 Subject selection
- 💻 Computer Science
- 🧬 Biology
- 🧪 Chemistry
- 📐 Mathematics
- 🌌 General Science
- ❤️ 5 hearts/lives
- ☠️ Traditional Hangman visualization
- 🔤 Letter guessing
- 🎯 Whole-word guessing
- 💡 Hint system
- 🎲 Random word selection
- ⭐ Score system
- 🏅 Player rank system
- 🏆 Leaderboard
- 🔁 Multiple rounds
- ✅ Input validation

## 🐍 Technologies Used

- Python 3
- Random module
- File handling
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- String operations

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python wordlock.py
```

## 🎯 How to Play

1. Choose a subject.
2. Read the subject-related question.
3. Guess the hidden word one letter at a time.
4. You have 5 hearts.
5. A wrong guess removes one heart and adds another part to the Hangman.
6. Use hints when needed.
7. You can also attempt to guess the complete word.
8. Earn points and receive a rank.
9. Your score can be added to the leaderboard.
